# Golosloom

Голосовой сервер (аналог Discord): чат с шифрованием, звонки, видео и демонстрация экрана. Веб-клиент на Vue и клиентское приложение на Tauri (полные копии), сервер на Go, медиа — LiveKit (SFU), TURN — coturn, SSL — Caddy, развёртывание — Docker Compose, база — SQLite.

## Структура репозитория

```
server/   — Go-бэкенд (REST + WebSocket, SQLite, LiveKit-токены, TURN-учётные данные)
web/      — веб-клиент Vue 3 (общий код и для Tauri)
desktop/  — Tauri-приложение (Rust-обёртка, Keychain; фронтенд — из web/)
deploy/   — docker-compose.yml, Caddyfile, livekit.yaml, .env.example, install.sh
.github/  — сборка установщиков Tauri для всех ОС/архитектур (GitHub Actions)
```

## Возможности

- **Каналы**: публичные и приватные (вход по приглашению от админа/модератора канала, приглашение по ID пользователя, приходит мгновенно, у офлайн-пользователей — при входе), каналы визуально разделены рамками.
- **Иерархия**: админ сервера (первый зарегистрированный, неуязвим, админ-панель поверх любого экрана) и группы «админ канала», «модератор канала», «пользователь»; права групп настраиваются админом сервера и применяются в рамках канала.
- **Чат**: E2E-шифрование (X25519 + общий ключ канала AES-256-GCM), обмен ключами при входе, история читается с нового устройства, пагинация, редактирование/удаление через ПКМ, у модераторов/админов — «Показать оригинал сообщения», звук только на чужие сообщения, защита от дубликатов и спама.
- **Звонки**: одному/нескольким/всем («Выбрать всех»/«Снять всех»), звук вызова 20 с, звук дозвона, «Войти в звонок» после отклонения, несколько звонков в канале, проверка на двойной вызов и дублирующие приглашения, завершение при пустом звонке, кнопка «Пнуть» (раз в 10 с), громкость каждого участника, шумоподавление, выбор микрофона, кнопка отключения всего звука.
- **Демонстрация экрана**: кодируется на клиенте, качество выбирает автор (1080p/60fps … 480p/30fps), зрители получают качество по своему интернету; при нескольких демонстрациях — миниатюры справа с никами, выбор активной; одна демонстрация — 90% окна.
- **Наказания**: бан на канале (навсегда, снимает админ сервера), бан на сервере (нельзя войти), кик (можно сразу вернуться), причина обязательна.
- **Клиент**: адаптивен (включая мобильные), адрес сервера вводится при первом запуске (смена VPS — без пересборки), статусы онлайн/офлайн, иконки ролей (👑 🛡️ ⚔️ 👤).

## Требования

- Go 1.26+, Node 22+, Rust (для Tauri), Docker (для сервера).
- VPS: Debian 13 или Ubuntu 24.04+, домен с A-записью на сервер, порт SSH.

## Установка на VPS (одна строка)

```bash
curl -fsSL https://raw.githubusercontent.com/grendervilll/golosloom/main/deploy/install.sh | sudo bash
```

Скрипт сам: проверит ОС (Debian 13 / Ubuntu 24+), установит недостающие зависимости (docker, ufw, git, openssl), запросит домен и порт SSH (по умолчанию 22), сгенерирует и сохранит все ключи и пароли в `.env` (права 600), откроет нужные порты в ufw, поднимет контейнеры, добавит cron для перевыпуска сертификатов.

Для полностью автоматической установки (без вопросов):

```bash
curl -fsSL https://raw.githubusercontent.com/grendervilll/golosloom/main/deploy/install.sh | DOMAIN=chat.example.com SSH_PORT=22 sudo -E bash
```

При повторном запуске скрипт предложит: **«Переустановить начисто»** (удаляются файлы, база данных и открытые порты, кроме SSH) или **«Обновить»** (скачиваются последние изменения с GitHub, база данных и порты не изменяются). Явные режимы:

```bash
sudo bash install.sh update      # обновление
sudo bash install.sh reinstall   # переустановка начисто
sudo bash install.sh uninstall   # полное удаление (включая БД, порты, cron)
```

### Открываемые порты

| Порт | Назначение |
|---|---|
| SSH (по умолчанию 22) | вход на сервер |
| 80, 443 | Caddy (HTTP/HTTPS) |
| 7880–7882 | LiveKit (API, WebSocket, TCP-fallback) |
| 50000–60000/udp | медиапотоки LiveKit |
| 3478, 5349 | TURN (coturn) |
| 49160–49200/udp | реле TURN |

## Локальная разработка

```bash
# Сервер
cd server && go run ./cmd/server   # http://localhost:8080

# Веб-клиент (Vite проксирует /api и /ws на сервер)
cd web && npm install && npm run dev   # http://localhost:5173

# Десктоп-клиент
cd desktop && npm install && npm run tauri dev
```

Веб-клиент и Tauri-приложение используют один и тот же код (`web/`): Tauri лишь обёртка с системной Keychain для ключей шифрования. Адрес сервера вводится при первом запуске приложения и доступен в настройках.

## Сборка десктоп-клиента

Локально (только для текущей ОС/архитектуры):

```bash
cd desktop && npm run tauri build
```

### Сборка для всех платформ через GitHub Actions

Установщики для **Windows (x86_64 и arm64)**, **macOS (Apple Silicon)** и **Linux (x86_64 и aarch64)** собираются автоматически в `.github/workflows/build-desktop.yml` одним из двух способов:

**1. По тегу (рекомендуется)** — при создании тега `v*` сборка сама публикует **GitHub Release** со всеми установщиками:

```bash
git tag v1.1.0
git push origin v1.1.0
```

**2. Вручную** — вкладка **Actions** репозитория → workflow **build-desktop** → кнопка **Run workflow** (без тега; результат — только артефакты, они хранятся 90 дней).

### Где скачать

- **GitHub Release**: страница репозитория → **Releases** → последний релиз — внизу списком лежат `.dmg` (macOS), `.exe`/`.msi` (Windows), `.deb`/`.AppImage` (Linux). Прямая ссылка: `https://github.com/grendervilll/golosloom/releases/latest`.
- **Артефакты** (без тега): Actions → выбранный запуск → раздел **Artifacts** → скачать архив (имя вида `golosloom-windows-x86_64`).

Примечания:
- macOS-сборка не подписана — при первом запуске: правый клик по приложению → «Открыть» (или «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно»).
- Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее → Выполнить в любом случае».
- Linux: `.deb` для Debian/Ubuntu, `.AppImage` — универсальный (chmod +x и запуск), `.aarch64` — бинарник для ARM-систем.

## Тесты

```bash
# Бэкенд (Go): права, регистрация, запрет регистрации, сообщения, нагрузка,
# вызовы, статусы, каналы, приглашения, шифрование-ключи, бан/кик, дубликаты, миграции
cd server && go test ./... -count=1

# Клиент (Vitest): криптография, пароли, чат, звонки, ключи каналов, WebSocket
cd web && npm test
```

## Шифрование

- У каждого устройства своя пара ключей **X25519**.
- У канала — общий симметричный ключ **AES-256-GCM**, который раздаётся участникам при входе, обёрнутый их публичными ключами (эфимерный X25519 + AES-GCM). Сервер хранит только обёрнутые ключи и шифротексты.
- Ключи хранятся на клиенте: веб — IndexedDB с non-extractable мастер-ключом WebCrypto; Tauri — системная Keychain (macOS Keychain / Windows Credential Manager / Linux Secret Service).
- При входе в канал ключ оборачивается для всех новых устройств; забаненный участник теряет доступ, но его сообщения остаются читаемыми для остальных.

## Звонки (LiveKit + coturn)

Медиа всегда идёт через TURN (coturn), без прямого подключения: вызов инициирован → ответ → разговор начинается без ожидания выбора подключения. Токены LiveKit выдаёт Go-сервер; временные учётные данные TURN генерируются по shared-secret. Кодирование экрана и камеры выполняется на клиенте, SFU только пересылает потоки.
