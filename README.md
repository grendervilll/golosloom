# Golosloom

Мессенджер со звонками: E2E-шифрованные чаты (Signal Protocol), голосовые и видео-звонки, демонстрация экрана, отправка файлов (текст/фото/видео до 100 МБ), поиск по сообщениям, ответы на сообщения, тёмная и светлая тема. Клиенты: веб (Vue 3), десктоп (Electron + Vue) и мобильный (Flutter/Android). Сервер на Go + Centrifugo, медиа — LiveKit (SFU), TURN — coturn, SSL — Caddy, развёртывание — Docker Compose, база — SQLite.

## Структура репозитория

```
server/   — Go-бэкенд (REST, Centrifugo, SQLite, LiveKit-токены, TURN-учётные данные)
web/      — веб-клиент Vue 3 (общий код и для десктопа)
desktop/  — Electron-приложение (safeStorage для ключей; фронтенд — из web/)
deploy/   — docker-compose.yml, Caddyfile, livekit.yaml, .env.example, install.sh
icons/    — исходники логотипа (лого сайта и иконка приложения)
.github/  — сборка установщиков Electron для всех ОС (GitHub Actions)
```

## Возможности

- **Каналы**: публичные и приватные (вход по приглашению от админа/модератора канала, приглашение по ID пользователя, приходит мгновенно, у офлайн-пользователей — при входе), каналы визуально разделены рамками.
- **Регистрация**: по умолчанию открыта; админ сервера может запретить её — тогда новые пользователи входят только по одноразовому приглашению (ссылка действует 5 минут, повторно использовать нельзя). Приглашение создаёт админ сервера или админ канала (кнопка «Пригласить зарегистрироваться» в шапке чата); приглашение из канала сразу даёт доступ к нему, даже если канал приватный. Статус регистрации («Разрешено»/«Запрещено» с цветным кружком) отображается в админ-панели и запоминается.
- **Иерархия**: админ сервера (первый зарегистрированный, неуязвим, админ-панель поверх любого экрана) и группы «админ канала», «модератор канала», «пользователь»; права групп настраиваются админом сервера и применяются в рамках канала.
- **Чат**: E2E-шифрование (Signal Protocol: X3DH + Double Ratchet для 1:1, Sender Keys для групп), автосинхронизация ключей между устройствами, история читается с нового устройства, пагинация, редактирование/удаление через ПКМ, у модераторов/админов — «Показать оригинал сообщения», удалённые сообщения скрыты у обычных пользователей, а админ/модераторы видят их с оригиналом, звук только на чужие сообщения, защита от дубликатов и спама; **смайлики и GIF**: кнопка 😊 слева от «Отправить», пикер с поиском и вкладками «Смайлики»/«GIF» (поиск GIF — Klipy через серверный прокси), короткое нажатие на GIF — отправка в чат, длинное — предпросмотр 40% окна без отправки.
- **Поиск и навигация**: поиск по расшифрованным сообщениям (в меню канала, с переходом к найденному), галерея «Фото и видео» чата, переход к сообщению по клику.
- **Ответы на сообщения**: по правой кнопке мыши или двойному клику; цитата ответа в пузыре, переход к исходному сообщению по клику на цитату.
- **Файлы**: вложения до 100 МБ (текст/фото/видео/любые); фото — просмотр без скачивания (ПКМ — «Сохранить как…»), видео — встроенный плеер; файл физически удаляется с сервера вместе с сообщением.
- **Звонки**: одному/нескольким/всем («Выбрать всех»/«Снять всех»), звук вызова 20 с, звук дозвона, «Войти в звонок» после отклонения, несколько звонков в канале, проверка на двойной вызов и дублирующие приглашения, завершение при <2 участниках (включая обрыв вкладки), кнопка «Пнуть» (раз в 10 с), громкость каждого участника (слайдер 0–200%), шумоподавление, выбор микрофона, кнопка 🔇 мгновенно глушит/возвращает звук только микрофонов собеседников (системные звуки не затрагиваются); голос кодируется opus 48 кГц, 96 кбит/с с эхо-подавлением и автоусилением.
- **Демонстрация экрана**: кодируется на клиенте, качество выбирает автор (1080p/60fps … 480p/30fps), зрители получают качество по своему интернету; при нескольких демонстрациях — миниатюры справа с никами, выбор активной; одна демонстрация — 90% окна; повторное нажатие кнопки «Экран» выключает демонстрацию; полный экран работает и в Electron.
- **Наказания**: бан на канале (навсегда, снимает админ сервера), бан на сервере (нельзя войти), кик (можно сразу вернуться), причина обязательна.
- **Клиент**: адаптивен (мобильный режим: каналы — вертикальный список), панель участников скрыта по умолчанию и открывается кнопкой 👥 (видна при любой ширине окна), адрес сервера вводится при первом запуске (смена VPS — без пересборки), статусы онлайн/офлайн, иконки ролей (👑 🛡️ ⚔️ 👤 — роль отправителя, а не текущего пользователя), логотип на страницах входа/регистрации и в шапке.

## Требования

- Go 1.26+, Node 22+, Docker (для сервера).
- VPS: Debian 13 или Ubuntu 24.04+, домен с A-записью на сервер, порт SSH.

## Установка на VPS (одна строка)

```bash
curl -fsSL https://raw.githubusercontent.com/grendervilll/golosloom/main/deploy/install.sh | sudo bash
```

Скрипт сам: проверит ОС (Debian 13 / Ubuntu 24+), установит недостающие зависимости (docker, ufw, git, openssl), запросит домен и порт SSH (по умолчанию 22), сгенерирует и сохранит все ключи и пароли в `.env` (права 600), откроет нужные порты в ufw, поднимет контейнеры, добавит cron для перевыпуска сертификатов.

Для полностью автоматической установки (без вопросов):

```bash
curl -fsSL https://raw.githubusercontent.com/grendervilll/golosloom/main/deploy/install.sh | DOMAIN=chat.example.com SSH_PORT=22 sudo -E bash
```

При повторном запуске скрипт предложит: **«Переустановить начисто»** (удаляются файлы, база данных и открытые порты, кроме SSH), **«Обновить»** (скачиваются последние изменения с GitHub, база данных и порты не изменяются) или **«Усилить безопасность»**. Явные режимы:

```bash
sudo bash install.sh update      # обновление
sudo bash install.sh reinstall   # переустановка начисто
sudo bash install.sh uninstall   # полное удаление (включая БД, порты, cron)
sudo bash install.sh lockdown    # закрыть все порты, кроме нужных (SSH сохраняется)
sudo bash install.sh harden      # fail2ban, SSH только по ключам, автообновления
```

### Безопасность

- **SSH**: по умолчанию порт 22 (задаётся при установке), вход только по ключам (`PasswordAuthentication no`, `PermitRootLogin prohibit-password`, `MaxAuthTries 3`).
- **fail2ban**: джейл для SSH (4 попытки → бан 1 ч) и для веб-входа (`401` на `/api/login` и `/api/register` — 5 за 5 мин → бан 2 ч); бан накладывается через ufw на все порты.
- **Rate-limit в приложении**: вход — 20 попыток/15 мин с IP, блокировка аккаунта на 15 мин после 8 неудач; регистрация — 15/15 мин с IP; ответ 429.
- **Файрвол ufw**: по умолчанию deny incoming, открыты только нужные порты.
- **Автообновления безопасности** ОС (unattended-upgrades).

### Открываемые порты

| Порт | Назначение |
|---|---|
| SSH (по умолчанию 22) | вход на сервер |
| 80, 443 | Caddy (HTTP/HTTPS) |
| 7880–7882 | LiveKit (API, WebSocket, TCP-fallback) |
| 50000–50100/udp | медиапотоки LiveKit (хватает на ~100 одновременных участников) |
| 3478, 5349 | TURN (coturn) |
| 49160–49260/udp | реле TURN (100 портов: 20 участников + демонстрации) |

## Локальная разработка

```bash
# Сервер
cd server && go run ./cmd/server   # http://localhost:8080

# Веб-клиент (Vite проксирует /api и /ws на сервер)
cd web && npm install && npm run dev   # http://localhost:5173

# Десктоп-клиент (Electron)
cd desktop && npm install && npm run dev
```

Веб-клиент и Electron-приложение используют один и тот же код (`web/`): Electron лишь обёртка с safeStorage для ключей шифрования. Адрес сервера вводится при первом запуске приложения и доступен в настройках.

## Сборка десктоп-клиента

Локально (только для текущей ОС):

```bash
cd desktop && npm run build
```

### Сборка для всех платформ через GitHub Actions

Установщики для **Windows**, **macOS** и **Linux** собираются автоматически в `.github/workflows/build-desktop.yml`:

**1. По тегу (рекомендуется)** — при создании тега `v*` сборка сама публикует **GitHub Release** со всеми установщиками:

```bash
git tag v2.0.0
git push origin v2.0.0
```

**2. Вручную** — вкладка **Actions** репозитория → workflow **build-desktop** → кнопка **Run workflow** (без тега; результат — только артефакты, они хранятся 90 дней).

### Где скачать

- **GitHub Release**: страница репозитория → **Releases** → последний релиз — внизу списком лежат `.dmg` (macOS), `.exe` (Windows), `.deb`/`.AppImage` (Linux). Прямая ссылка: `https://github.com/grendervilll/golosloom/releases/latest`.
- **Артефакты** (без тега): Actions → выбранный запуск → раздел **Artifacts** → скачать архив.

### Автообновление Electron

При запуске приложение проверяет GitHub Releases: если вышла новая версия — диалог «Обновить сейчас?» (Да/Позже); после скачивания приложение перезапускается.

Примечания:
- macOS-сборка не подписана — при первом запуске: правый клик по приложению → «Открыть» (или «Системные настройки → Конфиденциальность и безопасность → Открыть всё равно»).
- Windows SmartScreen может предупредить о неизвестном издателе — «Подробнее → Выполнить в любом случае».
- Linux: `.deb` для Debian/Ubuntu, `.AppImage` — универсальный (chmod +x и запуск).

## Шифрование

- **1:1 чаты**: Signal Protocol — X3DH (обмен ключами) + Double Ratchet (сессионное шифрование). Forward secrecy и post-compromise security.
- **Групповые чаты**: Signal Protocol Sender Keys — один ключ на группу, ротация при изменении состава.
- **Сервер**: хранит только публичные ключи устройств (identity key, signed pre-key, one-time pre-keys). Крипто-слепой — ретранслирует шифротексты.
- **Ключи хранятся на клиенте**: веб — IndexedDB; десктоп — Electron safeStorage (macOS Keychain / Windows DPAPI / Linux libsecret).
- **Файлы**: каждый файл шифруется уникальным AES-256-GCM ключом, ключ файла передаётся через Signal Protocol.

## Звонки (LiveKit + coturn)

Медиа всегда идёт через TURN (coturn), без прямого подключения: вызов инициирован → ответ → разговор начинается без ожидания выбора подключения. Токены LiveKit выдаёт Go-сервер; временные учётные данные TURN генерируются по shared-secret. Кодирование экрана и камеры выполняется на клиенте, SFU только пересылает потоки. Голос: opus 48 кГц моно, 96 кбит/с, эхо-подавление/автоусиление включены. Звонок автоматически завершается, когда участников остаётся меньше двух (в том числе при обрыве соединения/закрытии вкладки); звонок в ожидании (никто не ответил) живёт, пока в него можно войти через «Войти в звонок».

В десктопном приложении для микрофона/камеры/демонстрации заданы разрешения macOS (`Info.plist`): `NSMicrophoneUsageDescription`, `NSCameraUsageDescription`, `NSScreenCaptureUsageDescription`.

## GIF в чате (Klipy)

Поиск GIF идёт через серверный прокси (`server/internal/api/handlers_gifs.go`), ключ хранится только на сервере. В `.env` на VPS:

```
GIF_API_KEY=<ключ Klipy>      # partner.klipy.com → API Keys
```

Без ключа кнопка GIF показывает «Поиск GIF недоступен на этом сервере», остальное работает. Тестовый ключ Klipy — до 100 запросов/час; production-доступ запрашивается в Partner Panel.
